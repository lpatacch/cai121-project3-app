# CAI121 Project 3 App

A web app that runs your computer vision model inside a phone's browser. Nothing is uploaded: photos stay on the phone.

**What to change**
- `model/` — replace the 3 files with yours from `CAI121_project2_models` in your Drive: `model.onnx`, `classes.json`, `settings.json`.
- `features.js` — your app's name and purpose, test mode, "Not sure", and your 1 or 2 features.
- `my-feature.js` — extra credit only (optional).

**Don't change** `index.html`, `app.js`, `style.css`, or the `ort/` folder.

**Publish:** Settings → Pages → Deploy from a branch: `main`, `/ (root)` → Save. Then open `https://yourname.github.io/your-repo-name/` on your phone.

This template starts with the "everyday objects" model (MobileNetV2 trained on ImageNet, from the ONNX Model Zoo), so it works before you change anything.
